صفحة هبوط تسويقية مخصصة لحملات الإعلانات وجلب طلبات العملاء (Lead Generation) لمعرض **أوتو محمد نبيل**.

## 📁 هيكل المشروع

```text
Auto Nabil/
├── index.html               # صفحة الهبوط الرئيسية بتصميم متجاوب بالكامل مع الموبايل

└── README.md                # دليل التشغيل والرفع على Render.com
```

---

## 🚀 1. كيفية الرفع على Render.com (Static Site مجاني وسريع)

1. ارفع هذا المجلد إلى حسابك على **GitHub** في مستودع جديد (Repository).
2. ادخل على حسابك في [Render.com](https://dashboard.render.com).
3. اضغط على زر **New +** واختر **Static Site**.
4. اربط حسابك بـ GitHub واختر الـ Repository الخاص بالمشروع.
5. في إعدادات البناء (Build Settings):
   - **Name:** `auto-nabil` (أو أي اسم تفضله)
   - **Branch:** `main`
   - **Build Command:** اتركها فارغة (اترك الحقل فاضي).
   - **Publish Directory:** اكتب نقطة `.` أو اتركها فارغة (لأن ملف `index.html` في المجلد الرئيسي).
6. اضغط **Create Static Site**.
7. في ثوانٍ سيعطيك Render رابطاً مباشراً وسريعاً جداً ومجانياً مع شهادة أمان SSL تلقائية.

## 📊 2. ربط الفورم مع Google Sheets (خطوة بخطوة)

1. افتح حسابك في [Google Drive](https://drive.google.com) وأنشئ ملف **Google Sheets** جديد.
2. من القائمة العلوية داخل الشيت، اضغط على:
   `الإضافات (Extensions)` -> `Apps Script`.
3. افتح ملف `google_apps_script.js` الموجود في مشروعك، وانسخ كل محتواه والصقه داخل محرر Apps Script (بدلاً من أي كود موجود).
4. اضغط على أيقونة الحفظ (💾).
5. اضغط على الزر الأزرق أعلى اليمين **نشر (Deploy)** -> **نشر جديد (New deployment)**.
6. اضغط على الترس بجانب "تحديد النوع" واختر **تطبيق ويب (Web app)**.
7. اضبط الإعدادات كالتالي:
   - **الوصف (Description):** استقبال طلبات أوتو نبيل.
   - **التنفيذ كـ (Execute as):** أنا (Me - حسابك).
   - **من يملك حق الوصول (Who has access):** **أي شخص (Anyone)** *(مهمة جداً لتمكين الزوار من الإرسال)*.
8. اضغط **نشر (Deploy)**، وامنح الصلاحيات المطلوبة (Authorize access).
9. انسخ رابط تطبيق الويب (**Web app URL**).
10. افتح ملف `js/script.js` في مشروعك، والصق الرابط في السطر رقم 8:
    ```javascript
    const GOOGLE_SCRIPT_URL = "https://script.google.com/macros/s/AKfycb.../exec";
    ```
11. اعمل Commit و Push على GitHub، وسيتم التحديث التلقائي على Render فوراً!

## 📱 مميزات الـ MVP الحالي:
- **تحقق ذكي:** لا يقبل إلا أرقام هواتف مصرية صحيحة تبدأ بـ `010, 011, 012, 015`.
- **تجربة مستخدم كاملة للموبايل:** مريح للأصابع مع أزرار كبيرة وعنوان واضح.
- **تأكيد واتساب فوري:** بعد إرسال الطلب يظهر للعميل خيار لتأكيد طلبه ومواصفاته بضغطة زر تنقله للواتساب بالرسالة جاهزة ومكتوبة.
- **أزرار الاتصال السريع:** اتصال مباشر بأرقام المعرض الثلاثة بلمسة واحدة.
- **Demo Mode:** يعمل محلياً بكفاءة حتى قبل وضع رابط Google Script حتى تتمكن من معاينته واختباره فوراً.
